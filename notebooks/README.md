# Model training

Deliverable 2 work happens here:

1. Generate or load labeled rent-budget examples (`Comfortable` / `Stretch` / `Too High`).
2. Train a scikit-learn classifier.
3. Evaluate with accuracy / F1.
4. Export `../models/rent_fit_model.joblib`.

Starter script: `train_model_starter.py` (can be converted to `train_model.ipynb`).
